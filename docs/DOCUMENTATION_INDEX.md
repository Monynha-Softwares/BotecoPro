### Key Directories Explained

#### `/lib/core/`
**Purpose**: Core business logic and data management
- **models/**: All data entities (Product, Order, Table, etc.)
- **services/**: Business logic (DatabaseService, AuthService)
- **providers/**: State management with Provider pattern
- **device/**: Local storage and device-specific files

#### `/lib/presentation/`
**Purpose**: User interface layer
- **pages/**: Full-screen application views
- **widgets/**: Reusable UI components

#### `/docs/`
**Purpose**: Complete project documentation
- Architecture guides
- Deployment instructions
- Audit reports
- Quick references

#### `/web/`
**Purpose**: Web platform specific files
- HTML entry point
- PWA configuration
- Web assets

#### `/build/web/`
**Purpose**: Production-ready web build
- Compiled JavaScript
- Assets and fonts
- Service worker

### Important Files

| File | Purpose | Location |
|------|---------|----------|
| `main.dart` | App entry point | `lib/main.dart` |
| `theme.dart` | UI theme configuration | `lib/theme.dart` |
| `data_models.dart` | All data models | `lib/core/models/data_models.dart` |
| `database_service.dart` | CRUD operations | `lib/core/services/database_service.dart` |
| `auth_service.dart` | Authentication logic | `lib/core/services/auth_service.dart` |
| `shared_widgets.dart` | Reusable widgets | `lib/presentation/widgets/shared_widgets.dart` |
| `bottom_navigation.dart` | Navigation bar | `lib/presentation/widgets/bottom_navigation.dart` |
| `pubspec.yaml` | Dependencies | Root directory |
| `index.html` | Web entry | `web/index.html` |

### File Naming Conventions

- **Pages**: `*_page.dart` (e.g., `home_page.dart`, `products_page.dart`)
- **Services**: `*_service.dart` (e.g., `database_service.dart`, `auth_service.dart`)
- **Providers**: `*_provider.dart` (e.g., `auth_provider.dart`, `database_provider.dart`)
- **Widgets**: `*_widgets.dart` or descriptive names (e.g., `shared_widgets.dart`, `bottom_navigation.dart`)
- **Models**: Descriptive names (e.g., `data_models.dart`)

### Authentication System Files

The authentication system is implemented across multiple layers:

- **UI Layer**: `lib/presentation/pages/login_page.dart`, `lib/presentation/pages/signup_page.dart`
- **State**: `lib/core/providers/auth_provider.dart`
- **Logic**: `lib/core/services/auth_service.dart`
